# 媒体自动化批量下载脚本 (Media AutoDownloader)

用于自动化下载当前页面上的所有图片与 MP4 视频资源。脚本支持动态滚动抓取、基于链接去重、多图轮播连续下载、视频流嗅探拦截以及防风控拟人随机延迟。

---

## ⚠️ 重要运行前提

* **运行页面限制**：必须在**目标用户的个人主页**（展示作品卡片/网格瀑布流的页面）下执行。如果在其他页面运行，脚本将无法正确定位作品元素。
* **首次下载授权**：脚本触发连续下载时，浏览器地址栏右侧可能会弹出 **“是否允许该网站自动下载多个文件？”** 的提示，**必须点击“允许”**，否则后续文件会被浏览器拦截。

---

## 🚀 使用步骤

1. 打开目标浏览器（推荐 Chrome、Edge 等基于 Chromium 核心的浏览器），进入目标用户的**个人主页**。
2. 按键盘上的 **`F12`** 键（或按 `Ctrl + Shift + I` / Mac 用户按 `Cmd + Option + I`）打开开发者工具。
3. 在开发者工具顶部导航栏中，切换到 **`Console`（控制台）** 标签页。
4. **解除浏览器粘贴保护（首次操作必备）**：
* 现代浏览器默认会阻止向控制台粘贴复杂代码。
* 请在控制台输入光标处手动输入以下内容并回车：
```text
allow pasting

```


*(如果控制台显示为中文界面，可能需要输入 `允许粘贴` 后回车)*


5. 打开项目中的 `BrowserConsole.js` 文件，**复制里面的全部代码**。
6. 将复制的代码粘贴到浏览器的 **`Console`** 区域，按下 **回车键（Enter）** 执行。
7. 脚本将自动启动运行，你可以在控制台中实时查看下载进度与日志。

---

## 📌 功能特性

* **动态加载与去重**：随着瀑布流向下滚动，自动提取卡片并记录 `href`，彻底避免重复处理。
* **多图连载识别**：遇到图集作品时，自动检测右翻页按钮并连续点击下载，直到末尾（检测到 `forbidden` 状态）自动退出。
* **视频流嗅探**：同时拦截 `fetch`、`XMLHttpRequest` 与页面底层的 `<video>` 标签，自动拉取 MP4 媒体流并保存为本地文件。
* **防风控与拟人化**：卡片切换、翻页与滚动操作均内置毫秒级随机延迟（Jitter），降低触发平台自动化拦截的概率。

## 常见问题

* **遇到个别顽固视频弹窗提示？**
部分视频播放器需要手动交互才会建立流连接。当脚本弹出提示框时，请按照提示关闭提示框并在画面中央手动点一下播放，脚本捕获到 MP4 后会自动关闭弹窗并继续下一项。
* **点击后为什么直接在浏览器中播放而不是下载？**
脚本默认采用 Blob 数据流方式下载。如果个别视频 CDN 启用了严格的跨域限制（CORS），会降级为新标签页打开，此时可借助浏览器自带的“右键另存为”或下载插件保存。
